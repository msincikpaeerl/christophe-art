# Codes de secours

Les codes de secours vous permettent de vous connecter **si vous n'avez plus votre téléphone** (perdu, cassé, application effacée). Ils remplacent un code de l'application, voir [Activer la double authentification](activer-la-double-authentification.md).

## Comment ils fonctionnent

- Vous en recevez **10** lors de la configuration de la double authentification.
- Ils sont **affichés une seule fois**. Le site ne les garde pas en clair et ne peut pas vous les montrer de nouveau.
- Chaque code ressemble à `K7QM-2XPD-9TNA` et **ne fonctionne qu'une fois**. Les majuscules, les minuscules et les tirets n'ont pas d'importance.
- Ils ne remplacent pas le mot de passe : il faut toujours l'email et le mot de passe d'abord.

## Les conserver

Choisissez « Télécharger les codes (fichier texte) » au moment où ils s'affichent, ou recopiez-les. Rangez-les dans un endroit sûr, **pas sur le téléphone qui contient l'application** : par exemple un gestionnaire de mots de passe ou une feuille imprimée dans un tiroir fermé. Quiconque connaît votre mot de passe et un code de secours peut se connecter à votre place.

## Se connecter avec un code de secours

1. Saisissez votre email et votre mot de passe.
2. Sur la page « Code de vérification », ouvrez « Vous n'avez plus votre application ? ».
3. Saisissez un code de secours dans « Code de secours », puis « Utiliser ce code de secours ».

Ce code est alors consommé. L'utilisation est notée dans le journal d'activité.

## Voir combien il en reste

Menu avec votre nom, puis « Codes de secours ». La page indique le nombre de codes restants. **Quand il en reste 2 ou moins**, un avertissement s'affiche : générez un nouveau jeu avant d'être à court.

## Générer un nouveau jeu

Sur la page « Codes de secours », choisissez « Générer un nouveau jeu de codes ».

- Le site affiche 10 nouveaux codes, une seule fois, avec le bouton de téléchargement.
- **L'ancien jeu cesse de fonctionner immédiatement**, même s'il restait des codes non utilisés : remplacez vos notes.
- L'opération est notée dans le journal d'activité.

## Plus de téléphone ni de codes ?

Demandez à une autre personne de l'administration de **réinitialiser votre double authentification** (voir [Gérer les comptes](gerer-les-comptes.md#réinitialiser-la-double-authentification-dune-autre-personne)). Vous reconfigurerez ensuite l'application et recevrez de nouveaux codes de secours.
